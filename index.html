How to use · keyboard shortcuts
  • Orange □ = ON / ENTER (hold 3 s to turn off) · BACK previous screen · C clear · BKSP delete
  • Enter any values you know; the others are worked out (✓ entered, = computed, ? missing). Values are shared between screens, as on the CX-3
  • SET UNIT keeps the number and changes its unit · CONV UNIT converts the value to the next unit
  • ★ opens your favorite screen (SET › Favorite) · M memory: Recall, Store, Clear
  • H:M:S and D:M:S values fill in their colons as you type (013000 → 1:30:00); change Dur to HMS with CONV UNIT · Lat +N, Long +W · Inputs accept arithmetic, e.g. 120+15
  • Keyboard: digits, + - * /, Enter, Esc = BACK, Del = C, Backspace = BKSP, ↑ ↓, F/P/T/C/W/S/M, A = ★, U = SET UNIT, V = CONV UNIT, N = ±, R = √
