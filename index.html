Keyboard & tips
  • Enter = ENTER (hold 3 s = power off) · Esc = BACK · Del = CLR · Backspace = ◀
  • F FLT · P PLAN · T TIMER · C CALC · W W/B · S SET · M Favorites
  • K STO · R RCL · N +/− · : or ; time separator
  • ◀▶ on a value changes its units. Inputs accept arithmetic, e.g. 120+15.
  • Times: 1:30 = 1 h 30 min. Lat/Long: 40:30 = 40°30′, +/− for S/W.
